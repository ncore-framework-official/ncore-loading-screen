## English

### 0.5.1 — 2026-09-21

- final canonical layout for public distribution;
- operator configuration unified in `Config/config.js`, organized into readable sections with minimal comments; fallbacks and technical settings remain internal;
- JavaScript/CSS runtime moved to `Script/`;
- legal documents moved to `Licenses/`;
- `Package.toml` and `index.html` kept at package root for NANOS compatibility;
- final compliance with the active NCore visual charter, complete FR/EN localization, and stronger media/link validation;
- no new gameplay feature or Framework dependency added;
- anti-AI protection added to the license and source headers;
- official public Git target aligned with `ncore-framework-official/ncore-loading-screen`;
- audio playlist hardened against failure loops and public-safe mirror resynchronized;
- Discord/Git footer links protected against in-CEF navigation: click copies the URL;
- 0.5.1 runtime qualification closed for the published baseline;
- version 0.5.1 published on the nanos world Vault/Store on 2026-09-21.
