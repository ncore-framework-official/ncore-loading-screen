# Soutenir NCore Framework

<p align="center">
  <strong>Merci de soutenir le développement de NCore Framework.</strong>
</p>

NCore Framework est développé et maintenu comme un projet indépendant pour NANOS / nanos world.

Votre soutien contribue notamment à :

- financer le développement du framework et de ses packages officiels ;
- améliorer la documentation et les outils de qualification ;
- maintenir l'infrastructure publique du projet ;
- poursuivre les tests, l'optimisation et les futures releases.
